Part A

1. Valid indices for an array of length n go from 0 to n-1. If you try to read scores[n], you're going past the end of the array. This can give you a garbage value, crash, or seem to work even though its undefined behavior.

2. sizeof(scores) / sizeof(scores[0]) works in main because it can get the total size of the array and divide it by the size of one element. Inside a function, the array is treated like a pointer, so sizeof only gives you the size of the pointer, not the whole array.

3. board[1][2] is row 1, column 2, which is the second row and third column since indexes start at 0. C uses row-major order, which means it stores one whole row in memory before moving to the next one.

Part B

1. A function also needs the array length because when you pass an array, it becomes a pointer and doesn't tell the function how many elements there are. Without the length, it could go past the end of the array and read invalid memory.

2. The first index is the row and the second is the column. If you swap them, the code accesses the wrong elements. Since there are 3 teams and 4 columns, it could also go out of bounds and cause problems.
